# Animation Improvement Plans

Generated by `improve-animations` at commit `6b6e0f0` from the audit combining
`find-animation-opportunities`, `improve-animations`, and `emil-design-eng`.

Each plan is self-contained: exact file paths, current-code excerpts, target
values, and a feel check. An executor with zero context can run any plan whose
dependencies are met.

## Recommended execution order

1. **001** — easing tokens. Foundation; unblocks 003–007.
2. **002** — command palette (HIGH, independent). The clearest feel-bug; can run in parallel with 001.
3. **003** — scope `transition-all` across primitives. Highest reach once 001 lands.
4. **004** — sheet drawer curve.
5. **005** — FAQ accordion reveal.
6. **006** — copy-label crossfade.
7. **008**, **009** — independent LOW polish; run anytime.
8. **007** — landing scroll-reveal. Last, and optional — most likely to feel like too much motion for this crisp product; ship only if feel check approves.

## Dependencies

- 003, 004, 005, 006, 007 require **001** (the `ease-snappy` / `ease-smooth` /
  `ease-drawer` utilities).
- 002, 008, 009 are fully independent.

## Notes

- Token names deliberately avoid `--ease-out` / `--ease-in-out` (Tailwind v4
  built-ins) to prevent silently overriding existing `ease-out` usages. Emil's
  curves map: `--ease-snappy` = his ease-out, `--ease-smooth` = his ease-in-out,
  `--ease-drawer` = the Ionic drawer curve.
- Deliberately NOT animated (audit rejects, do not add): command palette (kept
  instant, see 002), secrets-table reveal/mask swap (functional data), skeleton
  pulse (already correct), modal zoom (already correct), origin-aware
  popover/dropdown/select (already correct).
- `execute` a plan with any agent, or run `improve-animations execute <plan>` to
  implement + review against the animation bar.
