- `packages/cli` service layer and `packages/crypto`: already deep, concentrated, tested — pattern to replicate, not refactor.

## Notes

- Token names deliberately avoid `--ease-out` / `--ease-in-out` (Tailwind v4
  built-ins) to prevent silently overriding existing `ease-out` usages. Emil's
  curves map: `--ease-snappy` = his ease-out, `--ease-smooth` = his ease-in-out,
  `--ease-drawer` = the Ionic drawer curve.
- Deliberately NOT animated (audit rejects, do not add): command palette (kept
  instant, see 002), secrets-table reveal/mask swap (functional data), skeleton
  pulse (already correct), modal zoom (already correct), origin-aware
  popover/dropdown/select (already correct).
- `execute` a plan with any agent, or run `improve-animations execute <plan>` to
  implement + review against the animation bar.
